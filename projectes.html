Per acabar el segon any del GM, vam haver de fer una aplicació web on veníem un servei i la pàgina havia de ser capaç de registrar usuaris a una BBDD

Com crear un projecte web pas a pas

  1. Fer una pluja d'idees per a que surtin possiblees maneres de desenvolupar una pàgina web
  2. Escollir les idees i dissenyar-les en un esborrany per a tenir clar com pot quedar el projecte
  3. Escollir les tecnologies a utilitzar, com els llenguatges de programació
  4. Crear el projecte pas a pas i dissenyar-lo per donar-li apariència
  5. Fer proves de la pàgina comprovant:
    • Que funcionen tots els enllaços
    • Que apareguin totes les imatges
    • Que els formularis funcionin
    • Que funciona a mòvil i a diferents navegadors,...
  6. Corregir els errors i publicar el projecte final
